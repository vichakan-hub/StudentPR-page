Percentile Rank

📚

รายละเอียดรายวิชา

⚠️

ความเสี่ยงของฉัน

📝

INSTALLATION

ติดตั้ง StudentPR เป็นแอป

เลือกอุปกรณ์ของคุณ แล้วทำตามขั้นตอนด้านล่าง สามารถเปิดใช้งานผ่าน Browser ได้โดยไม่จำเป็นต้องติดตั้ง

สแกนเพื่อเข้าใช้งาน

เลือก QR ให้ตรงกับอุปกรณ์

Desktop / Tablet StudentPR Desktop Mobile StudentPR Mobile
1
เปิด StudentPR Desktop

เปิดด้วย Google Chrome หรือ Microsoft Edge จากปุ่มเข้าใช้งานบนหน้าเว็บนี้

2
เลือกติดตั้งแอป

กดไอคอน Install ที่ Address Bar หรือเปิดเมนู Browser แล้วเลือกติดตั้ง StudentPR

3
ยืนยันการติดตั้ง

กด “ติดตั้ง” แล้ว StudentPR จะเปิดในหน้าต่างแอปและสามารถสร้าง Shortcut ได้

4
เปิดใช้งานได้ทันที

ครั้งถัดไปเปิด StudentPR จาก Desktop, Start Menu หรือ Shortcut ที่สร้างไว้

1
เปิด StudentPR Desktop

Tablet จะใช้หน้า StudentPR Desktop เพื่อให้พื้นที่แสดงผลครบถ้วน

2
Android Tablet

เปิด Chrome → เมนู ⋮ → เลือก “ติดตั้งแอป” หรือ “เพิ่มไปยังหน้าจอหลัก”

3
iPad

เปิดด้วย Safari → Share → Add to Home Screen → Add

4
เปิดจากไอคอน

StudentPR จะอยู่บนหน้าจอหลักของ Tablet เพื่อเรียกใช้ได้สะดวก

1
เปิด StudentPR Mobile

ระบบบนหน้าเว็บนี้จะตรวจจับ Smartphone และพาไปยัง Mobile Version อัตโนมัติ

2
Android

Chrome → เมนู ⋮ → “ติดตั้งแอป” หรือ “เพิ่มไปยังหน้าจอหลัก”

3
iPhone

Safari → Share → Add to Home Screen → Add

4
พร้อมใช้งาน

แตะไอคอน StudentPR จากหน้าจอหลักเพื่อเข้าใช้งานได้เหมือนแอป

HOW TO USE

ใช้งานง่ายใน 6 ขั้นตอน

ลำดับการใช้งานพื้นฐานเหมือนกันทุกอุปกรณ์ โดยหน้าจอจะปรับให้เหมาะกับ Desktop, Tablet และ Mobile

01

เข้าสู่ระบบ

เปิด StudentPR และกรอกข้อมูลเข้าสู่ระบบของนักเรียนให้ครบถ้วน

02

ดูภาพรวม

ตรวจสอบข้อมูลสำคัญและสรุปผลการเรียนของตนเองจากหน้าภาพรวม

03

เลือกภาคเรียน

เลือกชั้นหรือภาคเรียนที่ต้องการตรวจสอบเมื่อมีข้อมูลพร้อมให้แสดง

04

ดูรายละเอียด

เปิดดูรายวิชา หน่วยกิต เกรด GPA / GPAX และข้อมูลประกอบอื่น ๆ

05

ติดตามความเสี่ยง

ตรวจสอบรายการที่ควรติดตามเพื่อช่วยวางแผนการเรียนให้ทันเวลา

06

ตรวจสอบสถานะ

ติดตามข้อมูลสำคัญ เช่น ข้อมูลสอบแก้ตัว และการอัปเดตจากระบบ

PRIVACY & SECURITY

ข้อมูลของคุณสำคัญ

StudentPR เป็นพื้นที่สำหรับข้อมูลการเรียนของนักเรียน ควรใช้งานอย่างระมัดระวัง โดยเฉพาะเมื่อเข้าสู่ระบบจากอุปกรณ์ที่ใช้ร่วมกับผู้อื่น

✓
ไม่เปิดเผยข้อมูลเข้าสู่ระบบให้บุคคลอื่น
✓
ใช้ตัวเลือก “จำฉันไว้” เฉพาะอุปกรณ์ส่วนตัว
✓
ออกจากระบบทุกครั้งเมื่อใช้งานคอมพิวเตอร์สาธารณะ
✓
หากพบข้อมูลผิดปกติ ให้ติดต่อผู้ดูแลระบบของโรงเรียน
FAQ

คำถามที่พบบ่อย

ต้องติดตั้ง StudentPR ก่อนใช้งานหรือไม่?

ไม่จำเป็น สามารถเปิด StudentPR ผ่าน Browser ได้ทันที การติดตั้งเป็นเพียงตัวเลือกเพื่อให้เปิดใช้งานได้สะดวกเหมือนแอป

Tablet ต้องใช้ StudentPR เวอร์ชันไหน?

Tablet ใช้ StudentPR Desktop เพื่อให้การจัดวางข้อมูลเหมาะกับพื้นที่หน้าจอที่กว้างกว่าสมาร์ตโฟน

iPhone และ iPad ติดตั้งอย่างไร?

เปิด StudentPR ด้วย Safari จากนั้นกด Share → Add to Home Screen → Add

ทำไมยังไม่เห็นผลการเรียนบางภาคเรียน?

ผลการเรียนจะแสดงเมื่อข้อมูลของภาคเรียนนั้นพร้อมและได้รับการเผยแพร่ในระบบแล้ว

ใช้ StudentPR บนคอมพิวเตอร์ของโรงเรียนได้หรือไม่?

ใช้งานได้ แต่ควรออกจากระบบเมื่อใช้งานเสร็จ และไม่ควรเลือกให้ Browser จดจำข้อมูลเข้าสู่ระบบบนเครื่องที่ใช้ร่วมกัน

พร้อมเข้าสู่ StudentPR แล้วหรือยัง?

ตรวจสอบข้อมูลการเรียนของคุณได้จากทุกอุปกรณ์ ระบบจะเลือกเวอร์ชันที่เหมาะสมให้อัตโนมัติ
