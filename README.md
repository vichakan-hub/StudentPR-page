# StudentPR Promotional Landing Page

ไฟล์พร้อมอัปโหลดขึ้น GitHub Pages

## โครงสร้าง
- `index.html` หน้าเว็บหลัก
- `assets/studentpr-logo.png` โลโก้ StudentPR
- `assets/qr-desktop-tablet.png` QR สำหรับ Desktop/Tablet
- `assets/qr-mobile.png` QR สำหรับ Mobile

## URL ที่ตั้งค่าไว้
- Desktop / Tablet: https://vichakan-hub.github.io/StudentPR-desktop/
- Mobile: https://vichakan-hub.github.io/StudentPR-mobile/

## วิธีใช้
1. อัปโหลด `index.html` และโฟลเดอร์ `assets` ไปยัง Repository
2. เปิด GitHub Pages
3. หน้าเว็บจะตรวจจับอุปกรณ์และพาไปยัง StudentPR ที่เหมาะสม
4. Tablet ถูกกำหนดให้ใช้เวอร์ชัน Desktop
